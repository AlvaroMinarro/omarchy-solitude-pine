# Solitude Pine

Solitude Pine keeps Solitude's neutral desktop colors and pairs them with a Rosé Pine syntax palette. The accent is the pastel pine green `#459a88`.

## Install

```
omarchy theme install https://github.com/AlvaroMinarro/omarchy-solitude-pine.git
```

The GitHub repository name must remain `omarchy-solitude-pine` because Omarchy derives the theme slug from the URL basename.

`hyprland.lua` and terminal configs are omitted on purpose and generated from `colors.toml`.

Luffy and Zorro wallpapers are personal and are not distributed. Add your own images on the installed machine under `~/.config/omarchy/themes/solitude-pine/backgrounds/` or `~/.config/omarchy/backgrounds/solitude-pine/`.

Notifications, the lock screen, menu selection, and controls use a 3px left pine edge.

The notification center is a separate plugin, `omarchy plugin add https://github.com/jankeesvw/omarchy-notification-center.git --enable`.
